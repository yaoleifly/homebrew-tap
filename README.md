# homebrew-tap

[yaoleifly](https://github.com/yaoleifly) 的个人 Homebrew tap。

## 安装

```bash
brew install yaoleifly/tap/monk-pi
```

## 目录

| Formula / Cask | 说明 |
|---|---|
| `monk-pi` | 连接 [Pi Coding Agent](https://github.com/earendil-works/pi) 与 [Monk API](https://monk.party/) 的零配置 CLI（[项目主页](https://github.com/yaoleifly/monk-pi)） |
| `deeppet` (cask) | DeepSeek Harness 的 macOS 原生菜单栏伴侣 |
